## 主要功能:
- 支持FLV、M3U8、M3U、TS多种格式
- 稳定音量与"画质增强"
- 卡顿自动换源与手动换源
- 频道列表自动刷新
- EPG电视节目指南
- URL过滤黑名单 
- 自定义Headers
- 多码率、音轨、字幕切换(需直播源支持)，以及字幕翻译(chrome内置离线AI翻译)
- 实时字幕(chrome内置离线语音识别-SODA)
- 视频总结(基于实时字幕文本，浏览器内置离线AI summarizer，需满足一定的硬件条件)
## 使用方法:
- 打开"开发者模式"，"加载已解压的扩展程序"即可。
